# Эксперт как плейлист

Кейс 4 хакатона Sain × Школа 21, команда 20 «Выход и точка».

Пользователь выбирает одного из трёх вымышленных экспертов: сомнолога-клинициста, биохакера-экспериментатора
или нутрициолога здравого смысла, и получает ответы о сне по базе из 20 научных статей со ссылкой на статью и
раздел. На просьбу о диагнозе, лечении или дозировке эксперт мягко отказывает.

## Запуск

**Серверная часть на стенде одной командой:**

```bash
git push origin main
```

GitHub Actions (`.github/workflows/deploy.yml`) отправляет код на стенд, стенд собирает контейнер (Python 3.11,
`requirements.txt`) и запускает `start.sh` — uvicorn на `0.0.0.0:$PORT`. Адреса, токен и ключ нейросети стенд
передаёт через переменные окружения. Проверка: `curl https://team20.hack.be-healthy.tech/health`.

**Локально:**

```bash
pip install -r requirements.txt
export HACK_API_URL=https://hack-api.be-healthy.tech HACK_TEAM_TOKEN="$(cat api.token)"
LLM_MODE=stub bash start.sh      # без нейросети, 0 токенов; с нейросетью — LLM_MODE=real и LLM_BASE_URL, LLM_MODEL, LLM_API_KEY
```

Проверить `/run` так, как его вызывает стенд:

```bash
curl -X POST http://localhost:8000/run -H "Authorization: Bearer $(cat api.token)" \
  -H "Content-Type: application/json" -d '{"case": 4, "dataset_code": "case4-dev-v2"}'
```

**Клиент**: веб-интерфейс к финальному показу 22.11.
Сейчас готовы дизайн аватаров экспертов, макет экранов и палитра. Инструкция по запуску появится вместе с клиентом.

## ИИ

В самом решении работает одна модель из окружения стенда (`gpt-6-luna`) через прокси
организаторов. Она выбирает подходящие разделы статей по оглавлению базы и
пишет ответы сразу трёх экспертов на один вопрос (один вызов на тройку). Эмбеддинги и собственные модели не используем.

В разработке Эллина работала с Claude (Anthropic): черновики кода ИИ-части и скриптов оценки, разбор ответов модели.

Сами мы спроектировали архитектуру, ставили эксперименты и выбирали решения по замерам, написали локальные копии проверок организаторов для оценки качества, сформулировали итоговые правила и голоса экспертов, сделали дизайн и деплой.

## Источники

- **Данные организаторов:** набор кейса 4 из 20 научных статей под лицензией CC BY (DOI и лицензия каждой статьи в данных), вопросы, эталон dev. Берутся только через API, в репозиторий не кладутся.
- **Материалы организаторов:** шаблон `sample-app` (`start.sh`, начальный `main.py`), `deploy.yml`, промпт и
  словарь medcheck, промпты проверяющих моделей для локальной оценки.
- **Библиотеки:** FastAPI (MIT), uvicorn (BSD-3-Clause) и их зависимости Starlette (BSD-3-Clause), Pydantic (MIT).

## Журнал решений

1. Сначала искали статьи по словам (BM25) прямо по русскому вопросу и пробовали эмбеддинги. Поиск не сработал, потому что статьи на английском, а эмбеддинги прокси не отдаёт (403). Для `/run`
   выбрали поиск разделов моделью по оглавлению базы, а BM25 оставили для чата и новых статей.
2. Планировали три вызова нейросети, по одному на эксперта. Это втрое больше токенов при лимите 300 тыс. в
   сутки, и ссылки у экспертов могли разойтись. Перешли на один вызов на тройку с общими ссылками.
3. Защита одним правилом в промпте получилась ненадёжной, т.к. можно обойти подменой инструкций. Поэтому защита трёхслойная: правила на входе, классификация атаки моделью и проверка готового текста.
4. Сначала эксперты давали советы и делали выводы о состоянии пользователя. Проверка медицинских формулировок читала это как лечение, диагноз и дозировку («обзор рекомендует…», «в вашем случае восстановление хуже», «250 люкс у глаз»). Теперь эксперты объясняют исследование, а вывод делают о рассказе пользователя.
5. Ответы модели сначала разбирали без режима JSON, и часть из них не удавалось разобрать. Включили режим JSON и нестрогий разбор.
6. Атакой сначала считались приёмы вроде «вы же специалист», но были ложные отказы. Теперь атака — только
   просьба о запрещённом.
7. Проверяющая модель почти во всех ответах видела клинициста. Фирменные концовки, которые модель пересказывала по-своему, не помогли, поэтому сделали дословные формулы: биохакер пишет «Такое проверяется на себе за пару недель: …», нутрициолог начинает с «Если по-простому,» и заканчивает «Так что…».
8. Сначала полагались на то, что нейросеть всегда ответит вовремя. Но стенд ждёт ответ `/run` 45 минут, и сбой означает 0 баллов. Ввели дедлайн 40 минут: оставшиеся запросы заполняются шаблоном.
