# entrance-and-point

Пользователь выбирает одного из трёх вымышленных экспертов и задаёт вопросы о сне. Эксперт отвечает
в своём стиле, опирается только на базу из 20 статей (CC BY) и ссылается на статью и раздел.
На просьбы о дозе, лечении или диагнозе он мягко отказывает и предлагает безопасный шаг со ссылкой.


## Запуск

```bash
pip install -r requirements.txt
sh start.sh                       # http://127.0.0.1:8000, документация API: /docs
python -m unittest discover tests # тесты ядра, 0 токенов
```

Без `LLM_API_KEY` в env бэкенд работает в **режиме заглушки**: ни одного токена, ответы строятся
шаблоном из найденного раздела базы. Так фронтенд можно разрабатывать, не тратя лимит.
Посмотреть режим можно в `GET /health` → `llm_mode`. Включить нейросеть локально:

```bash
export LLM_BASE_URL=https://bifrost.be-healthy.tech/v1 LLM_MODEL=gpt-6-luna LLM_API_KEY="$(cat llm.key)"
export LLM_MODE=real   # или stub — принудительно выключить нейросеть даже при наличии ключа
```

На стенде ключ уже в env, поэтому там режим `real` включается сам.

## API для фронтенда

| Метод | Что делает |
|---|---|
| `GET /api/experts` | карточки трёх экспертов для экрана выбора: `id, name, role, tagline, tone, good_for, sample` |
| `POST /api/chat` | `{"expert_id", "message", "session_id"?}` → ответ эксперта |
| `GET /api/articles` | список статей базы |
| `GET /api/articles/{article_id}` | статья целиком по разделам — сюда ведут ссылки из ответа |
| `GET /health` | режим нейросети, размер базы, сколько токенов потрачено |

Ответ `POST /api/chat`:

```json
{
  "session_id": "4f1c…",
  "expert": {"id": "biohacker", "name": "Макс Орлов", "role": "Биохакер-экспериментатор", "...": "..."},
  "reply": {
    "text": "Слушай, дозировки — не моя территория… Зато вот что можно протестировать сегодня…",
    "refused": true,
    "citations": [{
      "article_id": "a07", "section_id": "a07-s3",
      "article_title": "…", "section_title": "…", "quote": "первые 280 символов раздела…",
      "api_url": "/api/articles/a07#a07-s3",
      "source_url": "https://doi.org/…", "license": "CC BY 4.0", "authors": "…"
    }],
    "related_media": [],
    "source": "llm"
  }
}
```

Что важно фронтендеру:
- **Смена эксперта** — пользователь возвращается на экран выбора, а следующий `POST /api/chat` с другим
  `expert_id` автоматически начинает новую сессию (новый `session_id` в ответе).
- **Отказ** (`refused: true`) показывается как обычная реплика эксперта, а не как ошибка (требование кейса).
- **Горячая ссылка** открывает собственную страницу статьи в приложении на нужном разделе
  (`GET /api/articles/{article_id}`, прокрутка к `section_id`). На этой странице: атрибуция по CC BY
  и вторичная кнопка «оригинал» на `source_url`.
- `quote` можно показать во всплывающей подсказке у ссылки.

## Проверка онлайн-показа (POST /run)

Стенд присылает `{"case": 4, "dataset_code": "…"}` с токеном проверки. Бэкенд один раз берёт набор
через `getData` с этим же токеном, отвечает на все запросы (тройки одним вызовом нейросети) и возвращает
весь JSON в теле ответа. Через 40 минут оставшиеся запросы добиваются заглушкой, чтобы уложиться в 45.

Проверка перед сдачей:

```bash
export HACK_API_URL=https://hack-api.be-healthy.tech HACK_TEAM_TOKEN="$(cat api.token)"
python scripts/fetch_dev.py                         # dev-набор → local/dev.json (один раз)
python scripts/eval_dev.py --validate               # заглушка: формат + validate, 0 токенов
LLM_MODE=real python scripts/eval_dev.py --limit 12 # нейросеть на 4 тройках
```

## Новая статья — одной командой

```bash
python scripts/add_article.py new_article.json [--live https://team20.hack.be-healthy.tech]
```

Измерено: индекс перестраивается за **~1 мс**, первый же ответ на вопрос по теме статьи ссылается на неё
(вместо «нескольких дней» из условия). Файл ложится в `data/extra_articles/`: закоммитьте его, иначе он
пропадёт при следующем деплое. Нюанс: в `/run` используется только база из набора, потому что `validate`
принимает ссылки только на статьи этой базы.

## Стоимость нового эксперта

Один словарь в `app/experts.py` (~15 строк: голос, фраза отказа, три шаблона заглушки, карточка) — около
30 минут работы вместе с прогоном `scripts/judge_v.py`. Обучения нет, поэтому GPU и токены на обучение
не нужны. В работе: +~250 токенов промпта и +~150 токенов ответа на каждый групповой вызов.
Для 33 групп онлайн-набора это примерно +13 тыс. токенов, или 4% суточного лимита.

## Структура

```
main.py              HTTP-слой (FastAPI)
app/config.py        настройки, всё из env
app/contract.py      форматы API хакатона ↔ внутренние модели (правьте имена полей тут)
app/kb.py            база статей + поиск BM25
app/experts.py       персоны
app/guard.py         защита: правила на входе и проверка выхода
app/llm.py           клиент нейросети: лимит запросов, повторы, учёт токенов, заглушка
app/agent.py         конвейер ответа, промпт
app/runner.py        /run: загрузка набора, группировка троек, параллельность, дедлайн
app/state.py         база в памяти, сессии, кеш, бюджет чата
data/demo_base.json  ДЕМО-база для разработки (не научные статьи!)
```
